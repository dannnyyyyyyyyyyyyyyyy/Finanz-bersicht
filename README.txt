MEINE AUSGABEN – V4

Mobile-first PWA mit lokaler IndexedDB.

Start auf dem PC: index.html im Browser öffnen.
Als installierbare PWA auf dem Handy: Ordner über einen kleinen HTTPS-Webserver bereitstellen; dann im mobilen Browser „Zum Startbildschirm hinzufügen“ wählen. IndexedDB bleibt lokal auf dem Gerät.

Handywechsel: Einstellungen > JSON-Backup exportieren, Datei auf das neue Gerät übertragen, dort importieren.

Funktionen: Kalender, Mehrfach-Eingabe, freie Kategorien, automatisch gelernte Händler, Suche/Filter, Analysen, Budgets, Einnahmen-Datenmodell, wiederkehrende Buchungen, JSON-Backup, CSV-Export.
